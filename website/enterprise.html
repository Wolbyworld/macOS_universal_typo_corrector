Installation Instructions

Download the DMG

Download Luzia-Enterprise.dmg from your company's shared drive or the link provided by IT.

📥 File: Luzia-Enterprise.dmg
📊 Size: ~15 MB

Open the DMG

Double-click the DMG file to open it. You'll see the Luzia app and an Applications folder shortcut.

Drag to Applications

Drag the Luzia Universal Typo Correcter app to the Applications folder. Wait for the copy to complete.

First Launch

Go to your Applications folder, find Luzia, right-click (or Control-click) the app, and select "Open". This is only needed the first time.

🔐 macOS will ask: "Luzia is from an unidentified developer. Are you sure?"
✓ Click "Open"

Grant Permissions

Luzia will request two permissions:

  • Accessibility: Required for copy/paste automation (click "Open System Settings" and enable)
  • Notifications: Optional, for error messages

You're Ready!

Luzia is now running in your menu bar (top-right corner). Select any text in any app and press ⇧⌘G (Shift+Command+G) to correct it.

✨ No API key setup needed—it's pre-configured!
⌨️ Keyboard shortcut: ⇧⌘G
📍 Menu bar icon: Look for the Luzia icon

⚠️ Troubleshooting

  • App won't open? Make sure you right-clicked and selected "Open" (not just double-clicked)
  • Not working? Check System Settings → Privacy & Security → Accessibility to ensure Luzia is enabled
  • Shortcut not working? The default is ⇧⌘G (Shift+Command+G). Check for conflicts in System Settings → Keyboard → Shortcuts
