LUZIA UNIVERSAL TYPO CORRECTOR
================================

INSTALLATION INSTRUCTIONS
=========================

1. Drag "Luzia Universal Typo Correcter" to the Applications folder
2. Open Applications folder
3. RIGHT-CLICK on "Luzia Universal Typo Correcter" → Open
4. Click "Open" when prompted (first time only)
5. Look for Luzia icon in your menu bar (top right)

FIRST USE
=========

1. Click the Luzia icon in menu bar
2. Grant Accessibility permissions when prompted
3. Select any text in any app
4. Press: ⇧⌘G (Shift + Command + G)
5. The text will be corrected automatically!

ENTERPRISE CONFIGURATION
========================

This is the ENTERPRISE version with pre-configured company proxy.
No API key needed - just install and use!

TROUBLESHOOTING
===============

• If nothing happens when pressing ⇧⌘G:
  Go to: System Settings → Privacy & Security → Accessibility
  Make sure Luzia has permission

• If you see "API key not set":
  You may have the wrong version installed.
  Make sure to install from THIS DMG.
